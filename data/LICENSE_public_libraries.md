# Public library location data licence

`public_libraries_2016_2018.csv` and `public_library_hex_bins_2018.geojson` are adapted from:

Carl Higgs (2023), *Australian public lending library locations (2016–2018)*, RMIT University Research Repository, [doi:10.25439/rmt.21944840.v1](https://doi.org/10.25439/rmt.21944840.v1).

The source is licensed [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). These two adapted files are shared under the same licence.

Adaptations: selected the 1,440 coordinate records within the mainland-and-Tasmania map extent, kept the columns needed for geographic inspection and attribution, and counted points in 115 km radius equal-area hexagonal cells. Three records from external islands are outside this map extent. State boundaries and award counts are separate data with their own sources documented in [`map_methodology.md`](map_methodology.md).
